# Nipah Satay™ Web App 🍢

> **Warisan Rasa Arang Asli – Authentic Malaysian Charcoal-Grilled Satay & Catering Web App**

## 🌟 Features
- **Interactive Menu Browser:**
  - 🍗 **Satay Ayam Tradisi** (Spiced tender chicken skewers)
  - 🥩 **Satay Lembu Empuk** (Succulent marinated beef skewers)
  - 🐐 **Satay Kambing Gula Melaka** (Premium spiced mutton skewers)
  - 🍚 **Nasi Impit & Kuah Kacang Set** (Compressed rice cubes with thick nutty gravy & fresh cucumber/shallots)
  - 🍱 **Combo Packs & Family Platters**
  - 🎪 **Live Grilling On-Site Catering Packages (200 to 500+ skewers)**
- **Triple Ordering Flow:**
  1. 🛵 **Delivery** (Direct doorstep delivery across Klang Valley with real-time fee calculation)
  2. 🏪 **Self-Pickup** (Pandu Lalu / Curbside ready pickup at 3 branch outlets)
  3. 🎪 **Event & Catering** (Interactive event booking with live pitmaster grilling station options)
- **Live Cart & Direct WhatsApp Checkout:**
  - Dynamic skewer calculation & customizable sauce preferences
  - Promo code discounts (`NIPAH10`, `KENDURI50`)
  - Instant WhatsApp pre-formatted order generator
  - Digital receipt modal & clipboard copy
- **Design & Performance:**
  - Built with React 18, Tailwind CSS, Google Fonts (Plus Jakarta Sans & Playfair Display), Lucide icons, Canvas Confetti.
  - Charcoal ember theme with glowing micro-animations and glassmorphism.
